Every log_entries row carries a SHA-256 hash chained off its predecessor. Any post-hoc modification to a row breaks every subsequent row's recomputed hash, surfacing the first tamper point. Verification is a read-only walk; runs on every load of this page.

Deleting, altering, or forging a row breaks every following row's recomputed hash. Read-only walk on each page load. Tamper-evidence is prospective from this feature's deploy; rows written before it are counted as pre-chain and not flagged.
